# ONYX GROUP — marketplace + buyer/cargo site V7

## Что добавлено

- Поиск товаров на Alibaba, 1688, Taobao, AliExpress, Poizon и Pinduoduo.
- Два сценария: самостоятельный переход на площадку и выкуп через ONYX GROUP.
- В карточке товара отдельные действия «Открыть источник» и «Заказать через ONYX».
- Калькулятор и индивидуальная заявка находятся в разных секциях.
- Расчёт переносится в заявку только по кнопке.
- Заявка сохраняется на backend и подготавливается для Telegram.
- Канал: `https://t.me/onyxgrouptg`.
- Менеджер заказов: `https://t.me/onyxshopadmin`.
- QR-код менеджера встроен в страницу.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:5000`.

## Как отправляется заявка

1. Клиент заполняет индивидуальную форму или корзину.
2. Сайт сохраняет заявку через `POST /api/order-requests`, если запущен `server.js`.
3. Текст заявки копируется в буфер.
4. Открывается официальная Telegram share-ссылка с подготовленным сообщением.
5. В окне подтверждения также доступны прямой чат `@onyxshopadmin` и повторное копирование текста.

На GitHub Pages backend недоступен, но Telegram-передача, QR-код, калькулятор и переходы на площадки продолжают работать.

## Трекинг

Трекинг работает по прежней схеме через `data/orders.json` и `/api/tracking`.
