# ONYX GROUP — финальный сайт V6

## Быстрый запуск с настоящим общим трекингом

```bash
npm install
npm start
```

Откройте `http://localhost:5000`.

## Как работает трекинг

- Клиент вводит трек-код в блоке «Отследить заказ».
- Менеджер раскрывает панель, вводит PIN и создаёт/обновляет заказ.
- При запуске через `server.js` статусы сохраняются в `data/orders.json` и видны с других устройств.
- Демо-PIN: `2026`. Перед публикацией задайте переменную `ADMIN_KEY`.

## GitHub Pages

На GitHub Pages работает весь интерфейс и локальное демо. Для общего трекинга разместите backend на Render/Railway и укажите URL в meta-теге `tracking-api` в `index.html`.

Пример:

```html
<meta name="tracking-api" content="https://your-backend.onrender.com/api/tracking">
```


## Финальные настройки V6

- Telegram: `https://t.me/onyxgrouptg`
- Клик по логотипу повторяет intro-анимацию.
