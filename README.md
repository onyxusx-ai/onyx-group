# ONYX GROUP V8 RESTORED

Эта версия построена **на полном V6**, а не вместо него. Все основные секции, интро-анимация, карта, калькулятор, трекинг, отзывы, FAQ, блог и контакты сохранены.

Добавлено поверх V6:
- поиск на Alibaba, 1688, Taobao, AliExpress, Poizon и Pinduoduo;
- переход к источнику из карточек товаров;
- отдельный блок индивидуального заказа;
- Telegram-заявка для @onyxshopadmin;
- QR-код менеджера;
- сохранение заявок на сервере в data/order-requests.json;
- облегчённые плавающие кнопки.

## Запуск

```bash
npm test
npm start
```

Открыть: http://localhost:5000

## GitHub Pages

Можно загрузить один `index.html`. Трекинг и заявки будут работать локально в браузере и через Telegram. Для общей базы между устройствами нужен запуск `server.js` на Render/Railway/VPS.
