# ИИ-помощник и подтверждение оплаты в Telegram

## Что видит обычный сотрудник

1. Откройте заказ.
2. В блоке **ИИ-помощник** выберите задачу:
   - объяснить следующий шаг;
   - написать поставщику в WeChat;
   - разобрать ответ поставщика;
   - подготовить ответ клиенту.
3. Вставьте текст и нажмите **Спросить помощника**.
4. Проверьте результат и самостоятельно скопируйте подходящий черновик.

ИИ ничего не отправляет, не подтверждает оплату и не меняет заказ. Перед отправкой номера карт, CVV, API-ключи и похожие последовательности маскируются. Запросы выполняются через OpenAI Responses API с `store: false`.

## Как сотрудник записывает перевод

1. В заказе откройте **Проверка оплаты**.
2. Введите сумму обычным числом: `1500` или `1500,50`.
3. Укажите банк/сервис и номер операции, если он есть.
4. Нажмите **Записать и подготовить Telegram**.
5. Откройте раздел **Автоматизация**.
6. У операции нужного заказа нажмите **Отправить в Telegram**.

В закрытый чат приходит карточка с суммой, заказом и кнопками. Бот не подключён к банку: администратор сначала сверяет реальное поступление в приложении банка, затем нажимает **Подтвердить** или **Отклонить**.

## Что настраивает владелец один раз

1. Создайте отдельного бота через официальный `@BotFather`.
2. Создайте закрытый чат для подтверждений и добавьте туда бота.
3. Подготовьте длинный случайный секрет webhook.
4. Узнайте цифровые Telegram-ID только тех сотрудников, которые могут подтверждать поступления.
5. Свяжите каждый ID с email существующего сотрудника ONYX.
6. Добавьте секреты Cloudflare:

```bash
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put OPENAI_MODEL
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_ADMIN_CHAT_ID
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET
npx wrangler secret put TELEGRAM_ADMIN_BINDINGS
```

Формат привязок:

```text
123456789:owner@example.com,987654321:manager@example.com
```

7. Зарегистрируйте HTTPS webhook:

```text
https://ВАШ-ДОМЕН/api/webhooks/telegram
```

При вызове Telegram `setWebhook` передайте тот же `secret_token` и разрешите `callback_query`.

8. В разделе **Как работать** проверьте, что Telegram и ИИ отмечены как готовые.
9. Создайте тестовый заказ и тестовый платёж на небольшую сумму.
10. Отправьте одну карточку вручную из раздела **Автоматизация** и проверьте обе кнопки.

Глобальный автоматический режим остаётся выключенным. Только после успешного теста владелец может задать `TELEGRAM_LIVE_APPROVED=true` и переключить правило в `live`. Это отдельное осознанное действие.

## Защита

- Telegram проверяется по заголовку `X-Telegram-Bot-Api-Secret-Token`.
- Подтверждать может только Telegram-ID, явно связанный с активным владельцем или менеджером ONYX.
- Проверяются закрытый чат и конкретное сообщение запроса.
- `update_id` сохраняется; повтор Telegram не обрабатывается второй раз.
- Каждому платежу соответствует только один Telegram-запрос.
- Ошибка отправки видна в очереди и допускает безопасный повтор.
- Токены и ключи не хранятся в базе и репозитории.
- ИИ не участвует в денежных расчётах и подтверждениях.

## Стоимость

Telegram Bot API не требует отдельной абонентской платы. OpenAI оплачивается по фактическому использованию выбранной модели. Для контроля расходов задайте лимит проекта OpenAI и начинайте с недорогой текстовой модели, доступной вашему аккаунту; идентификатор модели задаётся через `OPENAI_MODEL`, а не зашивается в код.
